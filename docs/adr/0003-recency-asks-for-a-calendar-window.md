# A recency phrase asks for a calendar window

Present-tense words such as current, now, and latest ask for a calendar span taken from the question. Prices, news, and weather ask for the 90 days ending on the reference date. An annual subject asks for the current calendar year. A question about a published report asks for that report's year, which is the year of the report actually cited.

The alternative was to treat those words as whatever row is newest in the Mart and return it as the current figure. That presented an older report year as the year the question asked for. When the cited report is earlier than the Recency window, the answer names both years.
