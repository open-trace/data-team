# The question's time wins over screen dates

Dates the client sends are the window only when the question names no time. A time phrase in the question is the window, and the screen dates do not widen, shrink, or replace it. "Prices last month" with the screen set to 2020 is still last month.

Retrieval today prefers the screen dates and uses the question's dates only when the screen is empty. That let a stale control silently replace "last month." The screen is a default for a question that never said when.
